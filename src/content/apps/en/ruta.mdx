## The problem

Small teams plan in spreadsheets nobody keeps up to date. Ruta puts what everyone is doing this week in a single view and warns you when someone is overloaded.

## What it does

- Drag tasks between days and people.
- Calculates each member’s workload and flags it in amber past 100%.
- Shows the week’s progress in a chart you can read at a glance.

## How it’s built

The frontend is a React island inside Astro; state syncs with **PostgreSQL** through a lightweight API. Heavy views render on the server so the first paint is instant.
