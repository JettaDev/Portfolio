# JettaDev · Portfolio

Portfolio personal con mis apps web.

Construido con [Astro](https://astro.build), [Tailwind CSS](https://tailwindcss.com) y MDX. Disponible en español e inglés.

## Desarrollo

```sh
npm install
npm run dev       # http://localhost:4321
npm run build     # genera dist/
npm run preview
```

## Añadir una app

1. Guarda una captura 16:10 en `src/assets/apps/<slug>.webp`.
2. Crea `src/content/apps/es/<slug>.mdx` y `src/content/apps/en/<slug>.mdx` (mira las existentes como plantilla).
